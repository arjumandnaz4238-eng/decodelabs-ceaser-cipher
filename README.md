# Caesar Cipher Tool - DecodeLabs Project 2

## Description
This project implements a basic cryptographic system using the **Caesar Cipher** algorithm in Python. It allows users to encrypt plain text into cipher text using a specified shift key and decrypt it back to its original form.

### Features:
* Encrypts plain text using custom shift keys.
* Decrypts cipher text back to plain text.
* Handles upper and lowercase letters accurately.
* Preserves spaces, special characters, and numbers.
